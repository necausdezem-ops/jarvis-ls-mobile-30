# J.A.R.V.I.S. Mobile v3.1

Projeto Android com interface holográfica revisada. O código-fonte está no arquivo `JARVIS-v3.1.tar.gz`; o workflow do GitHub Actions extrai, compila e publica o APK de depuração como artefato.

Abra a aba Actions para acompanhar o build. Ao concluir, baixe o artefato `JARVIS-debug-apk` e extraia `app-debug.apk` para instalar no Android.
